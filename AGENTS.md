# Agents: read CLAUDE.md first

This repository is a working prototype at a stable baseline. Agents may make **visual changes only**:
CSS, icons and markup polish. The data layer, calculations, migrations, tests and docs are off-limits.

The full rules are in [`CLAUDE.md`](CLAUDE.md): where you may work, what not to touch, what must stay visible,
fragile spots, and how to verify and commit.
